## Analytics Innovation Project: Player Performance Decision Tool

### Project Overview
This project proposes a player performance evaluation tool designed to support data-driven decision-making in a sports organization. The tool uses historical match data to create a standardized way of comparing players.

### Decision-Making Problem
Decision makers often lack time to evaluate new analytics tools and metrics. This tool helps simplify player evaluation and supports faster, more informed decisions.

### Proposed Analytics Approach
The tool uses player statistics such as goals, assists, minutes played, and pass accuracy to create a performance score. This may involve weighted scoring or basic predictive analysis.

### Use by Decision Makers
Coaches and managers can use this tool to compare players, select lineups, and make transfer decisions more efficiently.

### Connection to Chapter 7
This project is in the Creative Phase, where new analytics ideas are developed to support decision-making.
